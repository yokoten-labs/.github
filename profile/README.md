## yokoten-labs · 横展

**Tools that give AI coding agents the habits of a good software team.**

横展 (yokoten) comes from Toyota's shop floor: a lesson learned on one line spreads to
every line. We build tools that do the same for software made with AI agents.

### Projects

- **[yokoten](https://github.com/yokoten-labs/yokoten)**: a guide for the journey, a guard
  at the bridge. Guardrails and a five-stage guide for building software with AI agents:
  a guard that stops risky commands before they run, a road that names your next step,
  and CI checks that explain every finding. Zero dependencies.
  [yokoten.app](https://yokoten.app)

### How we work

Every change starts as an issue, goes through a pull request and its checks, and is
reviewed before it merges. Agents do the typing; a person decides what ships. Each
project's history is public, so you can see the process, not only the result.

### Get involved

Try yokoten on a project of yours, then
[open an issue](https://github.com/yokoten-labs/yokoten/issues) with what was hard.
That is the most useful thing you can give us.
