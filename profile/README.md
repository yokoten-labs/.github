## yokoten-labs · 横展

**yokoten stops your AI coding agent from making the mistake you can't undo. One command, no setup.**

横展 (yokoten) is a word from Toyota's shop floor: a lesson learned on one line spreads to
every line. We build tools that do the same for software made with AI coding agents.

### Projects

- **[yokoten](https://github.com/yokoten-labs/yokoten)**: a guard at the bridge, a guide for
  the road. The guard stops a force push, a wiped folder or a leaked key before it happens,
  in Claude Code, Codex, Gemini CLI, Copilot, OpenCode, Grok and DeepSeek. The road names your
  next step, from "safety net" to "a team of agents". Zero dependencies, MIT.
  `npx yokoten` · [yokoten.app](https://yokoten.app) · [npm](https://www.npmjs.com/package/yokoten)
  · English, 简体中文, 繁體中文, 日本語

### Built the way it teaches

yokoten is built by AI agents under its own rules: every change is an issue, a pull request,
the checks, then a review by a different AI model. A change to a hard line (the rules, the
workflows, the release) merges only with the owner's approval. 520+ merged pull requests,
1,900+ tests on Linux, Windows and macOS, 52 decision records, all public.

### Get involved

Run `npx yokoten` in a project of yours, then
[open an issue](https://github.com/yokoten-labs/yokoten/issues) with what was hard or unclear.
A stranger's first issue is the most useful thing this project can get.
